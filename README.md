# VocaVision

AI-Based Color, Clothing and Food Recognition Assistant. This vision-based assistive system identifies clothing colors/patterns and food items and describes them through voice output to support independent daily activities.

## Setup

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and add your Gemini API key.
4. Run the application: `python main.py`
